# tatutales.com.br

Landing page do canal **Tatu Tales**: histórias calmas para pequenos curiosos (2 a 6 anos).

Site estático publicado pelo GitHub Pages. A cópia de trabalho fica no repositório do canal, na pasta `site/`; este repositório só recebe a versão publicada.

Sem formulários, cookies, anúncios ou rastreadores.
